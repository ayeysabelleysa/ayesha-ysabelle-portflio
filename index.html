VictorianPass

Capstone ★
Project Manager · UI/UX Designer · Prompt Engineer · Web Developer
Live system: Done Redesign: Ongoing

A web system for Victorian Heights Subdivision that replaces laminated gate passes and paper logbooks with QR entry passes, so guards and admins can verify and record exactly who comes in. It also includes online amenity booking, letting residents reserve the clubhouse and courts without schedule conflicts.

VHEcoPoint

Capstone ★
Project Manager · UI/UX Designer · Prompt Engineer · Web Developer
Live system: Done Redesign: Ongoing

A smart waste station for Victorian Heights residents that sorts paper, plastic bottles, and aluminum cans into separate bins and verifies each drop-off with a QR scan linked to their VictorianPass account. Residents earn points for every recycled item and redeem them for amenity bookings, while admins monitor activity from one dashboard.
