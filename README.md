# Ayesha Ysabelle Catolico — UI/UX Portfolio

[![Live Demo](https://img.shields.io/badge/Live%20Demo-View%20Portfolio-ff86a9?style=for-the-badge&logo=vercel)](https://ayesha-ysabelle-portflio.vercel.app)
[![GitHub](https://img.shields.io/badge/GitHub-Repository-051f45?style=for-the-badge&logo=github)](https://github.com/ayeysabelleysa/ayesha-ysabelle-portflio)

A clean, responsive single-page portfolio showcasing my UI/UX design work, projects, and skills. Built with vanilla HTML, CSS, and JavaScript — no frameworks or build tools required.

## 🚀 Live Demo

**[View Live Portfolio](https://ayesha-ysabelle-portflio.vercel.app)**

## ✨ Features

- **Interactive Intro** — Click the clover key five times to unlock the portfolio, complete with petal animations and sparkle effects
- **Dark/Light Mode** — Toggle between themes with smooth transitions
- **Responsive Design** — Fully optimized for desktop, tablet, and mobile devices
- **Full-Screen Mobile Menu** — Elegant overlay navigation with smooth animations
- **Project Showcase** — Detailed case studies for VictorianPass, VHEcoPoint, and Click to Borrow
- **Interactive Toolbox** — Clickable tool keys with sparkle animations
- **Scrolling Ticker** — Animated marquee showcasing skills
- **Downloadable Resume** — Direct PDF download or printable resume page
- **Custom Cursor** — Clover-themed cursor for a unique touch
- **Smooth Animations** — Thoughtful micro-interactions throughout

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **JavaScript (Vanilla)** — Interactive features and animations
- **Fonts** — Bricolage Grotesque, Manrope

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/ayeysabelleysa/ayesha-ysabelle-portflio.git
```

2. Navigate to the project directory:
```bash
cd ayesha-ysabelle-portflio
```

3. Open `index.html` in your browser, or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .
```
